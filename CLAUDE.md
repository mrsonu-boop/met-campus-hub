# MET Campus Hub - Anti-AI-Slop & Styling Rules

1. UI/UX Rules (No AI Slop):
   - NEVER use purple or cyan gradients, glassmorphism mesh cards, or pill-shaped buttons.
   - NO fake metric counters, fake user review badges, or pulsing "live" dots.
   - NO vague hero headlines ("Elevate your experience"), emoji icons as main visuals, em dashes, or over-the-top scroll-driven animations.
   - Use clean, functional, high-contrast Tailwind UI with solid emerald (`emerald-600`) primary actions, crisp white/slate background cards, and clean typography.

2. API & Engineering Rules:
   - Always use Server-Sent Events (SSE) streaming via `ReadableStream` for AI responses.
   - Enforce multi-model fallbacks to guarantee 100% endpoint availability.
   - Ground all AI responses strictly in SPPU engineering syllabus concepts for MET BKC IOE Nashik.
